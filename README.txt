My Personal WL Tool Kit — PWA

Upload the CONTENTS of this folder to the root of your GitHub Pages repository (not the containing folder). Keep index.html, sw.js, manifest.webmanifest and icons/ together. Enable GitHub Pages and open its HTTPS URL in Chrome. Use Install app or Add to Home screen. Open once online before testing offline.

Security: Review all embedded personal information and datasets before using a public GitHub repository. Client-side passwords do not protect published source code.

Offline: the bundled toolkit works offline after caching, but Google Fonts, remote APIs, sync and externally loaded libraries may need a connection. Browser storage is per device/origin; export backups before replacing or clearing browser data. File-system folder access may require reauthorization and browser support.
