PWA DEPLOYMENT
1. Upload the CONTENTS of this folder to your GitHub Pages repository root (index.html, manifest.webmanifest, sw.js, icons/).
2. Enable GitHub Pages for the repository and open its HTTPS URL.
3. In Android Chrome, choose menu > Add to Home screen > Install.
4. Open the app online once before trying offline.

IMPORTANT: This source is a backup HTML and may contain embedded personal or sensitive tool data. Review and remove sensitive data before uploading to a PUBLIC GitHub repository. Public GitHub Pages is not a private storage service. Existing local browser data does not automatically transfer to a new origin. Use the app backup/restore workflow. External CDN dependencies may require network access unless separately bundled.
